## About the project
All-in-one **Kingdom Guard Spark** game enhancement platform featuring FPS monitoring, overlay tools, and config management.

The goal is a tool that just works — no clutter, no bloat.

## Quick start
1. Get the latest release from the download section above.
2. Unpack the downloaded archive to a folder of your choice.
3. Run the setup file and follow the on-screen instructions.

## 🔧 What it does
1. **Overlay Dashboard:** Real-time FPS counter, GPU temperature, and network stats on screen.
2. **Input Optimization:** Polling rate tuning, key remapping, and macro configuration.
3. **Replay System:** Match recording, highlight detection, and shareable clip export.
